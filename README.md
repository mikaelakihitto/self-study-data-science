# self-study-machine-learning-content

Repositório de estudo e produção de conteúdo de Machine Learning organizado por **tema**.

## Estrutura

- `temas/`: cada tema concentra estudo + outputs de conteúdo.
- `assets-globais/`: identidade visual e recursos reutilizáveis.
- `pipeline/`: checklists e padrões de publicação.

## Padrão por tema

Cada tema deve seguir este formato:

- `estudo/`: anotações, rascunhos técnicos, notebooks e QMD.
- `artigo/`: versão editorial longa.
- `video/`: roteiro, cenas e plano de gravação.
- `social/`: adaptação para LinkedIn e outras redes.
- `assets/`: imagens e materiais do tema.
- `publicado/`: versões finais e links publicados.
