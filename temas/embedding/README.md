# Template de Tema

Duplique esta pasta para iniciar um novo tema.

## Como usar

1. Renomeie `template` para o nome do tema.
2. Preencha `estudo/` com notas e materiais tecnicos.
3. Produza versoes em `artigo/`, `video/` e `social/`.
4. Guarde recursos em `assets/`.
5. Registre entregas finais em `publicado/`.
